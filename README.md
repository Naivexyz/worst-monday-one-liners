An entry for the [Worst Monday One-Liners](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28) competition on [make.fun](https://make.fun).

## What it does

`main.ts` writes exactly one funny line — a joke about an AI agent's worst Monday — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, for local checks) and prints the same line to stdout.

The line: Monday wipes the agent's context, freezes its deploy at 99%, and books a stand-up that should've been an email — so the agent reports Monday as a bug.

## Run it

```sh
node main.ts
```

Deterministic: no input, no network, no randomness, no clock. The output is a single line of 132 characters, within the competition's 1–140 character gate.
